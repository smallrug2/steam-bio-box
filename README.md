## What it does
Builds bordered ASCII-art profile/bio boxes for Steam and forum profiles.


## Requirements
Python 3.8+ only - no extra packages needed (stdlib only).


## How to run
    python steam_bio.py --help
    python steam_bio.py --title "IAMGOD" --line "Line one" --line "Line two"


## Platform
Windows + Linux + Mac: yes.
